├─ Clase BlastHole

│  ├─ Generación de nube de partículas

│
└─ Clase BlastAnimator (✨ Motor Principal)
   ├─ Ordenamiento automático por tiempo
   ├─ QTimer para sincronización (33ms = 30FPS)

   ├─ Señales: frame_updated, animation_finished
   └─ Controles: start, stop, pause, resume, reset

📊 FLUJO DE TRABAJO COMPLETO

Paso 1: Configuración de Malla
├─ Usuario ingresa parámetros (B, S, D, etc.)
├─ Click "Calcular Malla"
└─ Aparece malla 3D con taladros

Paso 2: Selección de Explosivos (⭐ NUEVO)
├─ Usuario elige explosivo de columna
├─ Configura cebo/booster
├─ Define longitud de taco
├─ Click "Validar Configuración"
└─ Sistema valida parámetros

Paso 3: Secuencia de Retardos
├─ Usuario selecciona retardos (Superficie/Fondo)
├─ Define intervalo entre taladros
├─ Click "Análisis de Tiros Cortados"
└─ Se muestra probabilidad de overlap

├─ Click "▶ Simular Voladura"
├─ Animación inicia automáticamente
├─ Se muestran cambios de color por taladro
├─ Escombrera se desplaza en tiempo real
└─ Animación se detiene cuando termina

Paso 5: Exportación (Fase 3)
├─ Click "📄 Exportar PDF"
├─ Se genera reporte con parámetros
├─ Incluye tabla de resultados
├─ Firma legal digital
└─ Se guarda como "Reporte_Voladura.pdf"
