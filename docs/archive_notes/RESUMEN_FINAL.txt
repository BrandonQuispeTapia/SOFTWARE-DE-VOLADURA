EJECUCIÓN:
──────────

   cd "e:\2026-1\datos\PROYECTO PERVOL\VOLADURA_PRO_10X"
   python main.py

   ✓ Se abre ventana principal
   ✓ Aparecen 4 pestañas
   ✓ PyVista 3D listo para visualización

FLUJO DE PRUEBA:
────────────────

1. Pestaña "Malla"
   → Ingresar parámetros (default ya configurados)
   → Click "Calcular Malla"
   → ✓ Aparece malla de taladros en 3D

2. Pestaña "Cebado y Carga"
   → Elegir explosivo, cebo, taco
   → Click "Validar Configuración"
   → ✓ Se confirma validez

3. Pestaña "Secuencia"
   → Elegir retardos
   → Click "Análisis de Tiros Cortados"
   → ✓ Se muestra riesgo (BAJO/MEDIO/ALTO)

4. Pestaña "Resultados"
   → Click "▶ Simular Voladura"
   → ✓ Animación inicia
   → ✓ Taladros detonan en secuencia
   → ✓ Escombrera se desplaza
