4️⃣ SIMULACIÓN VISUAL EXPLICADA

Lo que ves:
┌─────────────────────────────────────┐
│  VISOR 3D                           │
│                                     │
│  [Cilindros ROJO/GRIS]             │

│                                     │
│  [Nube de puntos AMARILLA]         │
│  └─ Escombrera (Muckpile)          │
│                                     │

│  └─ Referencia de coordenadas      │
└─────────────────────────────────────┘

ANIMACIÓN PASO A PASO:
├─ t=0ms:    Todos VERDE (standby)
├─ t=25ms:   Taladro 0 → AMARILLO (fuego)
├─ t=50ms:   Taladro 0 → Transparente + Taladro 1 → AMARILLO
├─ t=75ms:   Taladro 1 → Transparente + Taladro 2 → AMARILLO
├─ [continúa...]
└─ t=1100ms: Fin (todos vacios)

DURACIÓN: ~1.1 segundos (30 FPS)

8️⃣ TROUBLESHOOTING
──────────────────

Problema: "ModuleNotFoundError: No module named 'pyvista'"

Solución:
$ pip install --upgrade pyvista PyVistaQt PySide6

Problema: La GUI se congela

Solución:
→ Normal en primera carga (compilación Qt)
→ Espere 5-10 segundos
→ Si persiste: Reinicie el programa

Problema: No se ve la malla 3D

Solución:
→ Asegúrese de hacer click en "Calcular Malla" primero
→ Espere a que renderice (puede tardar 2-3s con 40 taladros)

Problema: La animación es lenta

Solución:
→ Reducir número de taladros (modificar GRID_ROWS/COLS en config.py)
→ O aumentar FPS (ANIMATION_FPS en config.py)
